# Dataset: UCI Human Activity Recognition Using Smartphones

- Source: https://archive.ics.uci.edu/dataset/240/human+activity+recognition+using+smartphones
- Task: 6-class classification (Walking, Walking Upstairs, Walking Downstairs, Sitting, Standing, Laying).
- Protocol: Subject-aware split (Train: 21 subjects, Test: 9 subjects).
- Download & Setup:
  1. Download `UCI HAR Dataset.zip` from the UCI repository.
  2. Extract it into `data/raw/` such that `data/raw/UCI HAR Dataset/features.txt` exists.
